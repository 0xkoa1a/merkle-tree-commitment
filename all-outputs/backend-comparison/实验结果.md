# 固定规模的 Python/C 后端对比

这不是 large 规模实验：固定 n=1024、消息 32 B、连续 k=64，分别在独立 Python/C 进程中测量 commit、open_many、verify_many；五组计时，每组目标 0.2 s。

[原始 JSON](jsons/backend-comparison.json) 同时保存两种后端的数据、输入、哈希工作量及 C 编译信息。建树约快 273 倍，批量验证约快 473 倍；不调用哈希的开封耗时基本不变。

独立工具 tools/compare_backends.py 默认写入这里，不参与两套规模实验的主入口。本组没有 SVG，不制作一套额外性能图。详见 [C 扩展介绍](../../docs/C扩展介绍及次要组实验结果.md)。
